## 第一幕：智能推荐（约 2:00）

### 操作
1. 回到首页，在模拟报志愿面板填入分数 `620`（如果已预填 620 则直接用）。
2. 底部显示"位次约 10,621"和冲稳保数量。
3. 点击 **"开始智能填报"** 或导航到"智能选大学"。
4. 智能选大学页：观察院校卡片列表、概率徽章、0% 概率极低态。
5. 切到"推荐查询"（/recommend），在输入框输入 `湖南物理620分帮我推荐学校`，点击提交。
6. 等待结果返回，展示冲/稳/保三档推荐卡片。

### 口播要点
> "系统按逐校最新年份的相关子查询构建候选集——消除全局年份窗口被零星数据污染的风险。
> 概率模型采用位次与分数双维加权融合（位次 75%、分数 25%），
> 并引入位次一票否决：位次差低于 -3000 名时概率强制为 0，不允许分数口径救回位次不可能的学校。
> 消融实验验证：开启否决后，不可能条目从 264 条降为 0 条。"

### 亮点提示
- **全量梯度**：每档返回全部达标候选（非 Top5 截断）
- **排序四级比较器**：概率降序 → 位次差降序 → 分数差降序 → 院校名
- **数据血缘**：每条结果标注 REAL/SIMULATED 来源

### 技术深挖（可选，面向技术评委）
- 切到管理后台"AI 管理"页，展示 AI 服务商配置（DeepSeek deepseek-v4-flash）、密钥加密存储不回显。

## 第二幕：AI 对话 Agent（约 2:30）

### 操作
1. 点击右侧悬浮球或导航进入 AI 对话工作台。
2. 点击"新对话"。

**轮次 1：智能推荐**
3. 输入 `帮我推荐学校`，发送。
   → 预期：调用 recommendSchools 工具，返回推荐卡片列表。

**轮次 2：按名加入**
4. 输入 `把中南大学加入志愿表`。
   → 预期：addPlanItem 按校名匹配（如果推荐列表中没有中南大学，系统正确拒绝并提示）。

**轮次 3：数据集外学校降级**
5. 输入 `查哈佛大学的计算机专业怎么样`。
   → 预期：getSchoolDetailByName 失败 → **失败改写层**自动用 LLM 通用知识补充回复，
   页面显示中性灰条"系统数据未命中，已由 AI 结合通用知识补充解答"（不再爆红）。

**轮次 4：删除确认**
6. 回到推荐结果，输入 `删除第1个`。
   → 预期：系统要求确认"确认删除第 1 个"。
7. 输入 `确认删除第 1 个`。
   → 预期：removePlanItem 执行，志愿表计数减 1。

**轮次 5：专业概览**
8. 输入 `计算机专业怎么样`。
   → 预期：getMajorOverview 返回专业概览（学科门类/学习内容/就业方向）。

### 口播要点
> "AI 对话采用四层决策链路：
> 第一层，意图词典规则对强意图直接短路执行，零 LLM 开销；
> 第二层，校准语义路由（借鉴 Jev 原理）通过类型化 Choice/Noul 决策和校准置信度门控实现高置信短路，
> 配有熔断器和影子模式，默认关闭可一键开启；
> 第三层，LLM 原生函数调用处理模糊语义；
> 第四层，工具硬失败时由失败改写层结合 LLM 通用知识补充回复，标注非本系统数据、禁止编造分数位次。
> 志愿表写操作采用双重安全控制：删除必须显式确认（空白归一化+否定守卫），
> 加入选校名匹配（拒绝推荐中不存在的学校）。"

### 亮点提示
- **四层决策**：不是简单的 prompt 进 prompt 出
- **失败改写**：不是 403 报错，而是有温度的 AI 补充回复
- **写操作安全**：双重确认 + fail-closed
- **283 个后端测试全绿**

## 录制注意事项

1. **浏览器准备**
   - 使用 Chrome 或 Edge，隐藏书签栏（Ctrl+Shift+B）
   - 缩放调至 100%（Ctrl+0）
   - 关闭开发者工具
   - 确保无弹窗拦截提示

2. **录制软件**
   - 推荐 OBS Studio（免费）或 Xbox Game Bar（Win+G）
   - 帧率 ≥30fps，分辨率 ≥1920×1080
   - 如果录屏 + 口播，建议分开录制后期合成

3. **演示节奏**
   - 每次点击后停 1-2 秒让观众看清结果
   - 数据加载时可以说"系统正在查询..."过渡
   - 不要快进或跳步——评委在意操作完整性

4. **应急预案**
   - 如果 AI 接口超时：说"AI 服务响应较慢，我们先看其他功能"然后切走
   - 如果页面加载慢：说"首次加载需要初始化缓存"然后等
   - 如果出现错误：F5 刷新后说"偶尔网络波动，刷新即可恢复"

5. **禁止事项**
   - 不要在演示中提到"哆啦A梦"（形象已重绘但口头提旧称呼会引导评委联想）
   - 不要在演示中说"测试账号"或"演示数据"以外的数据来源描述
   - 不要当场修改数据库或执行 SQL
   - 不要让评委看到 404 或 500 页面
