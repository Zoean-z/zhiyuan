# 功能设计优化（2026-08-20）

## 本轮边界

按用户最新要求，本轮保留原有颜色主题、品牌、导航名称、按钮名称和页面描述，不再进行视觉换肤或大范围文案重写，只处理功能流程、数据可信度和异常状态。

## 保留不变

- 原橙色视觉主题与页面布局风格。
- `智愿AI报考平台` 品牌名称。
- `智能选大学`、`AI 方案版`、`智能填充`、`智能排序` 等既有界面名称。
- 首页、登录页、咨询页、导航和侧栏原有文字描述。

## 功能优化

1. **查大学**
   - 支持从 `?q=` 查询参数进入院校搜索，并在同一路由参数变化时立即刷新关键词。
   - 删除没有真实依据的“搜索热度”和“保研率”排序。
   - 删除仅按数组顺序生成的“热门”标识。
   - 无最低分数据时显示“暂无”，排序时将缺失值放在末尾。

2. **智能选大学**
   - 删除由院校 ID 拼接的虚构专业组编号。
   - 结果数量按实际院校数统计。
   - 缺少最低分或概率时显示“暂无/待测”，避免 `null%`。
   - “待测”使用中性状态，不再被误标为低概率。
   - 分数输入下限修正为 100；缺少必要信息时给出明确提示，不再点击后无反应。
   - 将考生自己的选科显示为“当前筛选”，避免冒充院校官方选科要求。

3. **志愿表**
   - 三年数据统一调用 `cutoffHistory(...)`，不再由页面自行编造年度波动。
   - 删除公式伪造的招生人数、院校代码、保研率、软科/校友会排名和硕博点数量。
   - 明确区分后端录取数据与模型参考数据。
   - 修复“冲刺志愿不冲刺志愿”一类不通顺的咨询问题拼接。
   - 保留原来的“智能填充”“智能排序”按钮名称和视觉样式。

4. **一分一段**
   - 输入无效分数时给出 100–750 分范围提示，不再静默失败。

## 已有功能继续保留

- 志愿填报大数据板块删除。
- 顶栏选中横线位置修复。
- 未选择志愿表也能进行普通咨询。
- 本地 45 位志愿表自动同步为云端当前草稿。
